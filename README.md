# gemini-auto-reconnect
修复 Gemini 网页版在代理中断后需要刷新的问题 
Fix Gemini page refresh issue after proxy disconnection.

修复 Gemini 网页版在代理中断或网络切换后，左侧历史记录消失及无法发送对话的问题。无需手动刷新页面即可恢复连接。  
Fixes the issue where Gemini's conversation history disappears and new messages fail to send after a proxy disconnection or network switch. Restores connection without manual page refresh.

安装方法 / Installation

1.安装浏览器扩展 Tampermonkey (篡改猴)。

2.点击此处安装脚本 (Click here to install the script)。

3.刷新 Gemini 页面即可生效。
